# 화면 시안 (목업)

`index.html` — 나비효과플랜 카페 키워드 원고 작업 프로그램의 클릭 가능한 화면 시안입니다.

- 브라우저로 파일을 그냥 열면 바로 확인할 수 있습니다.
- 버튼과 탭 전환은 동작하지만 **글은 실제로 생성되지 않습니다.** 미리 준비된 예시 원고를 보여 줍니다.
- 화면 구성 근거는 [`../docs/기획서.md`](../docs/기획서.md)를 참고하세요.

## 혼자 열리는 파일로 만들기

`index.html`은 문서 뼈대(`<html>`, `<head>`)가 없는 본문만 담고 있습니다. 아래 명령을 돌리면 브라우저에서 바로 열리는 한 장짜리 파일이 `_site/index.html`로 만들어집니다.

```sh
node mockup/build.mjs
```

만들어진 파일 하나만 있으면 어디서든 열립니다. 메일로 보내거나 정적 호스팅에 그대로 올려도 됩니다.

구현이 시작되면 이 파일은 실제 화면(`public/`)으로 대체됩니다.
