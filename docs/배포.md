# 배포하기

이 프로그램은 **대표님 계정으로만** 올릴 수 있습니다. 제가 대신 눌러 드릴 수 없는 이유는 클라우드플레어 로그인이 대표님 브라우저에서만 되기 때문입니다.

둘 중 편한 쪽으로 하시면 됩니다. **1번은 터미널 없이 브라우저만으로 됩니다.**

---

## 1. 브라우저만으로 (권장)

1. [클라우드플레어](https://dash.cloudflare.com/sign-up) 가입 (무료)
2. 왼쪽 메뉴에서 **Compute (Workers)** → **Create** 버튼
3. **Import a repository** 탭 선택
4. **Connect GitHub** → `thogone02-svg/bephigh` 저장소 선택
5. 설정값을 이렇게 넣습니다

   | 항목           | 값                                              |
   | -------------- | ----------------------------------------------- |
   | Branch         | `claude/naver-cafe-manuscript-generator-fewgpa` |
   | Build command  | 비워 둠                                         |
   | Deploy command | `npx wrangler deploy`                           |

6. **Create and deploy** 클릭
7. 1~2분 뒤 `https://bephigh.<계정이름>.workers.dev` 주소가 나옵니다

이후에는 제가 코드를 고쳐 올릴 때마다 **자동으로 다시 배포**됩니다.

---

## 2. 터미널로

컴퓨터에 Node.js가 깔려 있어야 합니다.

```sh
git clone https://github.com/thogone02-svg/bephigh.git
cd bephigh
git checkout claude/naver-cafe-manuscript-generator-fewgpa
npm install -g pnpm && pnpm install

npx wrangler login     # 브라우저가 열리면 허용
pnpm deploy            # 끝나면 주소가 찍힙니다
```

## 올린 다음에 할 일

### 1. API 키 넣기 (필수)

1. [OpenAI](https://platform.openai.com/api-keys)에서 키 만들기
2. 배포된 주소 열기 → 오른쪽 위 **톱니 버튼** → **설정**
3. **OpenAI** 칸에 키 붙여넣고 저장

키는 대표님 브라우저에만 저장되고 서버에 남지 않습니다.

### 2. 구글 문서 (설정 안 해도 됩니다)

**설정 없이 쓰는 법** — 내보내기 → `구글 문서` → **서식 그대로 복사** 버튼을 누르고, 빈 구글 문서에 붙여넣으면 끝입니다. 키워드가 제목으로 들어가서 왼쪽 개요에 목차가 생깁니다. 여러 개를 골라도 한 번에 들어갑니다.

**버튼 한 번으로 문서까지 만들고 싶다면** 클라이언트 ID를 한 번 등록하면 됩니다. 앱의 **설정 → 구글 클라이언트 ID** 칸 아래에 만드는 방법과 넣어야 할 주소가 그대로 나와 있고, 주소는 복사 버튼으로 바로 가져갈 수 있습니다.

1. [Google Docs API 켜기](https://console.cloud.google.com/apis/library/docs.googleapis.com)
2. [사용자 인증 정보](https://console.cloud.google.com/apis/credentials) → **OAuth 클라이언트 ID 만들기** → **웹 애플리케이션**
3. **승인된 자바스크립트 원본**에 앱 설정 화면이 보여주는 주소를 붙여넣기
4. 만들어진 클라이언트 ID를 앱 설정 화면에 붙여넣기

### 3. 두 가지 확인 부탁드립니다

작업 환경에서 네이버와 구글 접속이 막혀 있어 제가 확인하지 못한 부분입니다.

| 확인할 것           | 어디서                    | 안 되면                          |
| ------------------- | ------------------------- | -------------------------------- |
| 카페 글 주소로 수집 | 보관함 → 카페 글 가져오기 | 화면에 뜬 오류 문구를 알려주세요 |
| 구글 문서 만들기    | 내보내기 → 구글 문서      | 화면에 뜬 오류 문구를 알려주세요 |

수집이 안 되더라도 **수집 버튼**과 **직접 붙여넣기**로는 됩니다.
