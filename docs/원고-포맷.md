# 원고 파일 포맷 (실제 전달본 기준)

전달받은 원고 1편(`코디세핀 재생크림 3개월 사용 후기`)에서 확인한 실제 형식입니다. 파서는 이 형식을 기준으로 만듭니다.

## 전체 구조

```
제목: 코디세핀 재생크림 3개월 사용 후기 (문제성 피부 내돈내산)

원래 피부 얘기는 잘 안 하는 편인데 이건 진짜 공유하고 싶어서 써봅니다 ㅎㅎ

제가 원래 예민성 피부라 환절기만 되면 볼이랑 입가가 빨갛게 뒤집어지고,

뭐만 바르면 따갑고 좁쌀 올라오는 스타일이에요.

[3개월 쓰면서 느낀 점]
- 자기 전에 바르고 자면 아침에 볼 붉은기가 확실히 가라앉아 있음
- 각질 올라오던 부위가 매끈해짐

댓글1
어 저 이거 본 거 같아요~ 진짜 자극 없어요??
└ 작성자
넵넵 저는 3통 비우는 동안 한 번도 따가운 적 없었어요 ㅎㅎ

댓글2
아 환절기 되니까 딱 뒤집어졌는데 흑흑 ㅜㅜ 이거 붉은기도 잡히나요?
ㄴ 작성자
자기 전에 바르고 자면 아침에 붉은기 확실히 가라앉아있어요!
ㄴ댓글2
오 대박... 혹시 순서는 어떻게 되나요?
ㄴ작성자
저는 토너랑 재생크림 이렇게 심플하게 써요!
ㄴ댓글2
감사해요 ㅜㅜ 저도 하나 주문해봐야겠어요!!

댓글3
헐 비포사진 저랑 피부 완전 똑같으세요 ㅠㅠ
ㄴ 작성자 저도 그 마음 너무 알아요 ㅠㅠ
```

## 읽는 규칙

| 부분          | 규칙                                                           |
| ------------- | -------------------------------------------------------------- |
| 제목          | `제목:` 으로 시작하면 그 뒤. 없으면 **첫 줄**                  |
| 본문          | 제목 다음 줄부터 첫 댓글 표기 전까지                           |
| 댓글 시작     | `댓글1` `댓글 1` `1.` 처럼 **번호가 붙은 줄**                  |
| 작성자 답글   | `└` 또는 `ㄴ` 로 시작하는 줄                                   |
| 댓글러 재답글 | `ㄴ댓글2` 처럼 답글 표시 뒤에 댓글 번호                        |
| 서식          | `**굵게**` 같은 표시는 지우고 본문만 남김 (문서에서 가져올 때) |

### 확인된 특징

1. **답글 표시는 `└` 와 `ㄴ` 두 가지가 섞여서 쓰입니다.** 둘 다 인식해야 합니다
2. 답글 라벨과 내용이 **같은 줄**에 붙기도 하고(`ㄴ 작성자 저도 그 마음…`), **다음 줄**로 떨어지기도 합니다. 둘 다 처리합니다
3. 화자 라벨은 **`작성자`** 입니다 (`글쓴이` 아님). 화면과 생성 결과 모두 `작성자`로 맞춥니다
4. 티키타카 길이는 댓글마다 다릅니다. 이 원고는 댓글1·3·4가 2턴, 댓글2가 5턴입니다
5. 본문에 `[소제목]` + `- 항목` 형태의 정리 블록이 들어갑니다
6. 문장 중간에서 줄을 바꾸고 문단마다 빈 줄을 둡니다 (모바일에서 세로로 길게 보이는 형태)
7. 말투: `ㅎㅎ` `ㅋㅋㅋ` `ㅜㅜ` `~` `..` 같은 표현을 자연스럽게 씁니다. 이모지는 쓰지 않습니다
8. 제품명은 본문에 자연스럽게 노출하고, 브랜드명은 굳이 넣지 않기도 합니다
