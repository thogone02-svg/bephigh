# 1주년 사이트 기획안

> 상태: 컨셉 기획 (개발 전) · 작성일 2026-09-16

## 0. 한 줄 요약

**「대한연애공사」** — 2003년쯤 망한 관공서 홈페이지처럼 생긴 가짜 기관이,
우리 연애 1주년을 공식 인증해 주는 사이트. 들어오면 증명서가 나오고,
기록물이 보관돼 있고, 반려동물을 등록할 수 있다.

---

## 1. 레퍼런스에서 뽑아낸 "재미의 공식"

좋아했던 레퍼런스들(키키키 여행사, 뉴진스 카드 발급기, 석가모니 앱)을
분해해 보면 재미의 출처가 겹칩니다.

| 공식                       | 설명                                                   | 어디서 나왔나            |
| -------------------------- | ------------------------------------------------------ | ------------------------ |
| ① 가짜 기관의 **진짜 문서** | 존재하지 않는 조직이 내려주는, 저장·인쇄 가능한 결과물 | 키키키 티켓 PDF, 뉴진스 ID카드 |
| ② **입력 → 발급**의 의식    | 내 정보를 넣어야 나만의 것이 나옴. 과정 자체가 재미     | 카드 발급기 키오스크     |
| ③ **하찮은 반복**           | 염주 108번 탭, 걸음 수. 의미 없는데 쌓이면 뿌듯함      | 석가모니 앱              |
| ④ **재화 → 꾸미기**         | 모은 걸로 옷 갈아입히기                                 | 연꽃/부티크, 싸이 도토리 |
| ⑤ **의도적 촌스러움**       | 세련되게 만들면 재미없음. 과장해야 웃김                | 전부                     |

→ 이 다섯 개를 한 세계관 안에 다 넣을 수 있는 껍데기를 고르는 게 기획의 핵심.

## 2. 컨셉 3안 비교

### A안. 「대한연애공사」 — 관공서 / 발급소 ★ 추천

옛날 공공기관 홈페이지 + 민원 키오스크. 창구마다 다른 기능.

- 장점: 공식 ①②⑤가 컨셉에 그냥 박혀 있음. 관공서 서식(표, 도장, 형광 노랑,
  절취선, 바코드)은 키치 소재로 최상급. 기능을 "창구"로 계속 붙일 수 있어 확장이 쉬움.
- 단점: 남친이 관공서 감성을 모르면 한 박자 늦게 웃김 → 발급물 자체가 귀여우면 커버됨.

### B안. 「미니홈피 복각」 — 싸이월드

도토리, 미니미, 미니룸, 사진첩, 다이어리, 일촌평, BGM 자동재생.

- 장점: 원하던 3가지 기능(사진첩 / 옷입히기 / 동물 키우기)이 **전부 원래 있던 기능**이라 억지가 없음.
- 단점: 레트로에 가깝고 키치·Y2K 색이 옅음. 그리고 "복각"이라 내 기획이라기보단 재현이 됨.

### C안. 「1주년 OS」 — 가짜 운영체제 데스크톱

부팅 화면 → 바탕화면 아이콘 → 창 여러 개, 작업표시줄에 D+365 시계.

- 장점: 확장성 최고. 도트하우스 레퍼런스가 정확히 이 모양. 비주얼 임팩트 큼.
- 단점: **남친은 100% 폰으로 열어봄.** 창 드래그·멀티윈도우는 모바일에서 다 죽음. 난이도도 제일 높음.

### 결론

**A안 추천.** B안의 좋은 점(사진첩·꾸미기·키우기)은 A안 안에 창구로 흡수 가능하고,
C안의 리스크(모바일)는 A안에 없음. A안 화면 하나하나는 그냥 "세로로 긴 문서"라
모바일이 오히려 자연스러움.

## 3. A안 상세 — 「대한연애공사」

### 3-1. 세계관

> 대한연애공사는 2003년 설립되어 대한민국 연인들의 교제 이력을 관리해 온
> 기관입니다. 귀하의 1주년 도래를 확인하였으므로 아래 민원을 처리해 주시기 바랍니다.

톤: 끝까지 진지한 공문체. 근데 내용이 "귀하는 애교 등급 3급으로 판정되었습니다" 같은 거.
이 낙차가 전부입니다.

### 3-2. 화면 구조

```
[정문] 출입증 발급 — 사귄 날짜 6자리 입력 (예: 250214)
   │
[로비] 번호표 뽑기 → 창구 목록 (2003년 홈페이지 스타일, 공지사항·방문자 카운터·움짤 배너)
   │
   ├─ 1번 창구 · 증명서 발급과      ← 핵심
   ├─ 2번 창구 · 기록물 열람실      ← 사진첩 (아이디어 1)
   ├─ 3번 창구 · 반려동물 등록과    ← 키우기 (아이디어 3)
   ├─ 4번 창구 · 성장기록 보관소    ← 여자친구 키우기 (아이디어 2)
   ├─ 5번 창구 · 민원 접수          ← 남친이 나한테 민원 넣기
   ├─ 6번 창구 · 오늘의 운세        ← 하루 1회 뽑기
   └─ 7번 창구 · 폐쇄됨 🔒          ← 1주년 당일 00:00에만 열림
```

### 3-3. 창구별 내용

#### 1번 창구 · 증명서 발급과 ★ MVP

입력 폼(촌스러운 민원 신청서) → 발급 버튼 → **프린터 드르륵 애니메이션 + 도장 쾅**
→ 이미지 저장 / 공유.

발급물 3종:

1. **연애 1주년 증명서** — 상장처럼 생긴 세로 문서. 성명, 교제 개시일, 경과일수(D+365),
   특기사항("상습 애교"), 발급기관 직인.
2. **커플 등본** — 세대주/세대원 표에 둘이 들어가 있음. 관계란에 "애인". 비고란에 웃긴 멘트.
3. **연인 신분증(ID카드)** — 뉴진스 카드 그거. 사진 + 별명 + 좋아하는 것 + 소속.
   지갑에 넣게 실물 인쇄 가능한 비율로.

> 디테일 포인트: 발급 전에 "수수료 0원 (사랑으로 결제되었습니다)" 영수증 한 장 더 뱉기.

#### 2번 창구 · 기록물 열람실 ★ MVP

사진첩. 그냥 갤러리 아니고 **국가기록원 문서고**처럼.

- 연/월별 서류철(파일 바인더) 아이콘 → 열면 사진들이 슬라이드 필름처럼 들어 있음
- 사진 클릭 → 공문서 서식 캡션: `촬영일시 / 장소 / 사건개요 / 담당자 소견`
- 일부 사진은 "일부 내용 비공개" 검은 마스킹 → 클릭하면 벗겨짐 (제일 웃길 듯)
- 스크롤 끝에 "총 N건의 기록이 보관 중입니다"

#### 3번 창구 · 반려동물 등록과

남친이 고양이/강아지 좋아하니까 여기가 재방문 유도 담당.

1. 입양 신청 → 종·이름 정하기 → **동물등록증 발급** (1번 창구랑 같은 발급 엔진 재사용)
2. 등록 완료되면 키우기 화면 해금
3. 매일 1회 출석 + **밥그릇 108번 탭** (석가모니 염주 그거) → `사랑마일리지` 적립
4. 마일리지로 옷·모자·방석·배경 구매해서 꾸미기
5. 총 마일리지에 따라 3단계 성장 (아기 → 중간 → 다 큼)

> 난이도 관리: 실시간 육성 시뮬 X. 하루 1회 출석 체크 + 누적 포인트 + 이미지 3단계면 충분.

#### 4번 창구 · 성장기록 보관소

"우리 애기 성장 기록" — 내 아기 때 얼굴이 점점 자라는 그거.

- **런타임에 AI 안 돌림.** 미리 5~6장 뽑아서 이미지로 박아넣기.
- 슬라이더를 드래그하면 단계가 바뀌고, 단계마다 관공서 신체검사표 같은 캡션
  (`연령: 0세 / 신장: 50cm / 특이사항: 잘 웃음`)
- 마지막 단계에 실제 지금 얼굴 사진

#### 5번 창구 · 민원 접수

남친이 나한테 민원을 넣는 곳. `민원 유형: [불만/건의/칭찬/기타]`, 내용 입력 →
접수번호 발급 → "처리기한: 영업일 기준 3일 이내". 내용은 메일이나 폼으로 나한테 전달.
없어도 되지만 있으면 제일 많이 웃을 기능.

#### 6번 창구 · 오늘의 운세

하루 한 번. 커플 운세 + 오늘의 데이트 미션 뽑기. 재방문 장치.

#### 7번 창구 · 폐쇄됨 🔒

평소엔 자물쇠 + "본 창구는 2026-XX-XX 00:00부터 운영됩니다".
1주년 당일이 되면 열리고 안에 **편지 + 영상**. 진짜 하고 싶은 말은 여기에.

## 5. 기술 / 난이도

프레임워크 없이도 됩니다. 정적 사이트 + 브라우저 저장소면 끝.

| 기능             | 방법                                       | 난이도 |
| ---------------- | ------------------------------------------ | ------ |
| 전체             | 정적 HTML/CSS/JS (또는 Vite + React)       | 쉬움   |
| 배포             | Cloudflare Pages / Vercel — 무료           | 아주 쉬움 |
| 증명서 이미지 저장 | `html-to-image`로 PNG 저장                 | 쉬움   |
| PDF              | `jsPDF`에 위 PNG 얹기 (모바일은 PNG 권장)  | 쉬움   |
| 사진첩           | `public/photos/` + `photos.json` 한 파일   | 아주 쉬움 |
| 키우기·마일리지  | `localStorage` + 날짜 비교                 | 쉬움   |
| 108번 탭         | 카운터 + 진동(`navigator.vibrate`)         | 쉬움   |
| 성장 기록        | 미리 만든 이미지 6장 + 슬라이더            | 쉬움   |
| 입장 코드        | 클라이언트에서 문자열 비교 (보안 아님, 연출) | 아주 쉬움 |
| 당일 해금        | `new Date()` 비교                          | 아주 쉬움 |
| 민원 접수        | 폼 → 메일 전송 서비스 / 구글폼             | 쉬움   |

**서버 없음 · DB 없음 · 로그인 없음.** 이게 난이도를 낮추는 핵심입니다.

### 주의할 것

- 모바일 우선. 남친은 카톡으로 링크 받아서 폰으로 엽니다.
- 자동 재생 음악은 iOS에서 막힘 → 음소거 버튼을 눌러야 나오게
- `localStorage`는 브라우저 지우면 날아감 → 중요한 건(편지) 저장소에 의존 금지
- 사진 용량. 원본 올리면 느려짐 → 1200px, webp로 줄여서 넣기

## 6. 만드는 순서

| 단계 | 할 일                                    | 결과                     |
| ---- | ---------------------------------------- | ------------------------ |
| 1    | 디자인 톤 + 발급물 1종 시안              | 이게 되면 나머지는 복붙  |
| 2    | 정문 + 로비 + 1번 창구                   | **이것만 있어도 완성품** |
| 3    | 2번 창구 (사진첩)                        | 분량 담당                |
| 4    | 7번 창구 (숨긴 편지)                     | 감동 담당                |
| 5    | 3번 창구 (동물 키우기)                   | 재방문 담당              |
| 6    | 4·5·6번 창구                             | 여유 되면                |

2~4단계까지가 **꼭 필요한 범위**, 5단계부터는 선택입니다.

## 7. 준비물 (개발 전에 모아야 할 것)

- [ ] 사귄 날짜, 1주년 날짜
- [ ] 서로 이름·별명, 좋아하는 것, 소속(신분증에 들어갈 항목)
- [ ] 사진 20~40장 + 사진마다 한 줄 캡션(날짜/장소/무슨 일)
- [ ] 남친이 키울 동물: 고양이 / 강아지, 이름
- [ ] 내 아기 사진 1장 (성장 기록용) + AI로 뽑은 중간 단계 5장
- [ ] 1주년 당일 편지 글 (+ 영상)
- [ ] 마스킹하고 벗겨서 보여줄 "웃긴 사진" 몇 장
- [ ] 도메인 쓸지 여부

## 8. 정해야 할 것

1. **1주년이 언제?** — 역산해서 일정을 잡아야 함
2. **남친이 개발자인지** — 맞으면 소스 뜯어볼 테니 이스터에그를 코드 주석에도 심기
3. 3안 중 A안으로 갈지, 아니면 B안(싸이월드) 감성이 더 끌리는지
4. 기능 욕심 어디까지 — 위 "만드는 순서" 4단계까지 vs 6단계까지
