# 1. 한 장 요약

**「대한연애공사」** — 2003년쯤 만들어지고 방치된 관공서 홈페이지처럼 생긴
가짜 기관이, 우리 연애 1주년을 공식 인증해 주는 사이트.

사귄 날짜를 입력해야 문이 열리고, 안에는 창구가 일곱 개 있다.
증명서를 발급받고, 기록물(사진)을 열람하고, 반려동물을 등록해서 키운다.
7번 창구는 1주년 당일 00시에만 열린다.

- 대상: 남자친구 1명
- 보는 기기: **폰 100%** (카톡으로 링크 받아서 엶)
- 개발: 서버 없음 · DB 없음 · 로그인 없음. 정적 사이트 + 브라우저 저장소
- 톤: 끝까지 진지한 공문체인데 내용이 "귀하는 애교 등급 3급으로 판정되었습니다"

# 2. 레퍼런스 분석 — 재미의 공식

참고한 것: 키키키 여행사 사이트(kiiikiii.kr), 뉴진스 카드 발급기, 석가모니 앱,
blume / natalie brunswick / tini weenie mail club / dollhouse (키치 웹디자인)

분해해 보면 재미의 출처가 겹칩니다.

| # | 공식 | 설명 | 출처 |
|---|------|------|------|
| ① | **가짜 기관의 진짜 문서** | 존재하지 않는 조직이 내려주는, 저장·인쇄 가능한 결과물 | 키키키 티켓 PDF, 뉴진스 ID카드 |
| ② | **입력 → 발급의 의식** | 내 정보를 넣어야 나만의 게 나옴. 과정 자체가 재미 | 카드 발급기 키오스크 |
| ③ | **하찮은 반복** | 염주 108탭, 걸음 수. 의미 없는데 쌓이면 뿌듯 | 석가모니 앱 |
| ④ | **재화 → 꾸미기** | 모은 걸로 옷 갈아입히기 | 연꽃/부티크, 싸이 도토리 |
| ⑤ | **의도적 촌스러움** | 세련되게 만들면 안 웃김. 과장해야 재밌음 | 전부 |

→ 이 다섯을 한 세계관에 다 담을 수 있는 껍데기를 고르는 게 기획의 전부.

# 3. 컨셉 3안과 결론

### A안 · 「대한연애공사」 — 관공서 / 발급소 ★ 권장

옛날 공공기관 홈페이지 + 민원 키오스크. 창구마다 다른 기능.

- **좋은 점** — 공식 ①②⑤가 컨셉에 그냥 박혀 있음. 관공서 서식(표, 도장, 형광 노랑,
  절취선, 바코드)은 키치 소재로 최상급. 기능을 "창구"로 계속 붙일 수 있어 확장이 쉬움.
  모든 화면이 세로로 긴 문서라 폰에서 자연스러움.
- **걸리는 점** — 공문체 개그라 한 박자 늦게 웃김. 발급물 자체가 예뻐야 커버됨.

### B안 · 「미니홈피」 — 싸이월드 복각

도토리, 미니미, 미니룸, 사진첩, 다이어리, 일촌평, BGM 자동재생.

- **좋은 점** — 원하는 3가지 기능(사진첩 / 옷입히기 / 동물 키우기)이
  **원래부터 있던 기능**이라 억지로 끼워 넣을 데가 없음. 도토리 하나로 전 화면이 연결됨.
- **걸리는 점** — 키치·Y2K보다는 레트로에 가까움. 이미 있던 걸 되살린 거라
  "내가 기획한 것"이라는 느낌이 옅어짐.

### C안 · 「1주년 OS」 — 가짜 운영체제 데스크톱

부팅 화면 → 바탕화면 아이콘 → 창 여러 개, 작업표시줄에 D+365 시계.

- **좋은 점** — 확장성 최고. 비주얼 임팩트 큼. dollhouse 레퍼런스가 정확히 이 모양.
- **걸리는 점** — **남친은 폰으로 봄.** 창 드래그·멀티윈도우가 모바일에서 다 죽음. 난이도도 최상.

### 결론

**A안으로 가되, 3번 창구 안쪽만 B안의 미니룸으로 만든다.**

겉은 끝까지 관공서인데, 동물등록증 받고 들어간 한 칸만 미니홈피 미니룸.
A의 개그(①②⑤)와 B의 재방문 장치(③④)를 둘 다 가져가면서 세계관은 안 깨집니다.
C안은 버립니다 — 모바일 리스크가 장점을 못 이깁니다.

# 4. 최종안 상세 — 대한연애공사

## 4-1. 세계관

> 대한연애공사는 2003년 설립되어 대한민국 연인들의 교제 이력을 관리해 온
> 기관입니다. 귀하의 1주년 도래를 확인하였으므로 아래 민원을 처리해 주시기 바랍니다.

**톤 규칙 — 이게 전부입니다.**
- 문장은 100% 공문체. 절대 깨지 않음 ("~하시기 바랍니다", "~에 해당합니다")
- 웃긴 건 **내용**에서만 나옴 ("특기사항: 상습 애교 3급", "처리기한: 영업일 기준 3일")
- 이모지 쓰지 않음. 대신 ◆ ▶ ※ ■ 같은 특수문자
- 남친 이름 대신 "귀하", "민원인"

## 4-2. 사이트 구조

```
[정문]  출입증 발급 — 교제개시일 6자리 입력
   │
[로비]  번호표 뽑기 → 창구 목록
   │     (2003년 홈페이지: 파란 헤더 · 흐르는 공지 · 방문자 카운터)
   │
   ├─ 1번 창구 · 증명서 발급과       ← 핵심. 발급물 3종
   ├─ 2번 창구 · 기록물 열람실       ← 사진첩
   ├─ 3번 창구 · 반려동물 등록과     ← 등록증 발급 + 미니룸 키우기
   ├─ 4번 창구 · 성장기록 보관소     ← 아기 얼굴 → 지금 얼굴
   ├─ 5번 창구 · 민원 접수           ← 남친이 나한테 민원 넣기
   ├─ 6번 창구 · 오늘의 운세         ← 하루 1회 뽑기
   └─ 7번 창구 · 폐쇄됨 🔒           ← 1주년 당일 00:00 개방 (편지)
```

## 4-3. 창구별 상세

### 1번 창구 · 증명서 발급과 ★ 최우선

입력 폼(촌스러운 민원 신청서) → 발급 버튼 → **종이가 드르륵 밀려나오고 도장 쾅**
→ 이미지로 저장 / 공유.

발급물 3종:

| 발급물 | 내용 |
|--------|------|
| **연애 1주년 증명서** | 상장처럼 생긴 세로 문서. 성명 / 교제개시일 / 경과일수(365일) / 특기사항 / 직인 |
| **커플 등본** | 세대주·세대원 표에 둘이 들어감. 관계란에 "애인". 비고란에 웃긴 멘트 |
| **연인 신분증** | 뉴진스 카드 그것. 사진 + 별명 + 좋아하는 것 + 소속. 지갑에 넣을 실물 비율 |

> 디테일: 발급 직후 영수증 한 장 더 뱉기 — `수수료 0원 (사랑으로 결제되었습니다)`

### 2번 창구 · 기록물 열람실 ★ 최우선

사진첩. 갤러리가 아니라 **국가기록원 문서고**.

- 연/월별 서류철 탭 → 열면 사진들
- 사진마다 공문서 캡션: `촬영일시 / 장소 / 사건개요 / 담당자 소견`
- 일부 사진은 검게 마스킹 + "일부 내용 비공개" → 탭하면 벗겨짐 ← 제일 웃길 부분
- 하단에 `총 37건 보관 중 · 페이지 1/9`

### 3번 창구 · 반려동물 등록과

남친이 고양이/강아지를 좋아하니 여기가 재방문 담당.

1. 입양 신청 → 종·이름 정하기
2. **동물등록증 발급** (1번 창구와 같은 발급 엔진 재사용)
3. 등록 완료 → **미니룸** 해금 (여기만 B안 감성)
4. 매일 1회 출석 + **밥그릇 108번 탭** → `사랑마일리지` 적립
5. 마일리지로 옷·모자·방석·배경 사서 꾸미기
6. 누적 마일리지 3단계 성장 (아기 → 중간 → 다 큼)

> 난이도 관리: 실시간 육성 시뮬 안 함. 하루 1회 출석 + 누적 포인트 + 이미지 3단계면 충분.

### 4번 창구 · 성장기록 보관소

"우리 애기 성장 기록" — 내 아기 때 얼굴이 점점 자라는 그것.

- **런타임에 AI 안 돌림.** 미리 5~6장 뽑아 이미지로 박아넣기
- 슬라이더를 끌면 단계가 바뀌고, 단계마다 관공서 신체검사표 캡션
  (`연령 0세 / 신장 50cm / 특이사항: 잘 웃음`)
- 마지막 단계는 실제 지금 사진

### 5번 창구 · 민원 접수

남친이 나한테 민원을 넣는 곳.
`민원 유형: 불만 / 건의 / 칭찬 / 기타` + 내용 → 접수번호 발급
→ `처리기한: 영업일 기준 3일 이내`. 내용은 메일이나 폼으로 전달.
없어도 되지만 있으면 제일 많이 웃을 기능.

### 6번 창구 · 오늘의 운세

하루 한 번. 커플 운세 + 오늘의 데이트 미션 뽑기. 재방문 장치.

### 7번 창구 · 폐쇄됨

평소엔 자물쇠 + `본 창구는 2026-XX-XX 00:00부터 운영됩니다`.
1주년 당일이 되면 열리고 안에 **편지 + 영상**. 진짜 하고 싶은 말은 여기.

# 5. 화면 시안 명세

각 화면을 위에서부터 순서대로 적었습니다. 그림을 그리거나 이미지를 생성할 때
이 순서와 문구를 그대로 쓰면 됩니다. 화면 비율은 전부 **세로 폰 (9:19.5)**.

## A안 화면

### A-01 · 정문 (입장)

- **목적** — 사귄 날짜를 알아야 들어올 수 있음. 몰입 시작점
- **배경** — 남색 그라데이션 (#16388F → #0D2358 → #081A42). 키오스크 기계 안쪽 느낌
- **요소 (위 → 아래)**
  1. 상단 작은 글씨: 좌측 `대한연애공사` / 우측 픽셀체 `SINCE 2003`
  2. 형광 노랑 간판 — 검정 2px 테두리 + 오른쪽 아래 offset 그림자, 자간 넓게 `출 입 증 발 급`
  3. 흰 안내문 박스 (검정 테두리) — `귀하의 1주년 도래가 확인되었습니다. 본인 확인을 위해 교제개시일 6자리를 입력하십시오.` ("1주년 도래"에 형광 노랑 형광펜)
  4. 6칸 코드 입력 — 흰 네모 6개, 검정 테두리, 픽셀 숫자 `2 5 0 2 1 _`. 5번째 칸은 형광 노랑으로 깜빡임
  5. 형광 노랑 `확 인` 버튼
  6. 하단 고정: 회색 키패드 판 (4×3), 회색 키캡에 1~9·0·←·OK. ← 와 OK만 형광 노랑
- **포인트** — 뉴진스 카드 발급기의 "아래쪽 물리 키패드"가 핵심. 이게 있어야 기계처럼 보임

### A-02 · 로비

- **목적** — 창구 목록. 2003년 관공서 홈페이지 그 자체
- **배경** — 흰색
- **요소 (위 → 아래)**
  1. 파란 헤더 바 (#1B4FBF) — 좌측 흰 글씨 `대한연애공사`, 우측 픽셀체 `KOREA LOVE CORP.`
  2. 형광 노랑 띠 — 위아래 검정 선, 글씨가 오른쪽→왼쪽으로 흐름
     `◆ 제 1주년 교제 인증 민원을 접수받고 있습니다 ◆ 수수료 없음 ◆`
  3. 번호표 — 갱지색 바탕에 점선 테두리. `대기번호` / 빨간 픽셀 숫자 `001` / `앞에 기다리는 분 0명`
  4. 창구 목록 7줄 — 각 줄에 파란 사각 번호 뱃지 + 이름 + 오른쪽 `›`, 점선 구분선
     `1 증명서 발급과 / 2 기록물 열람실 / 3 반려동물 등록과 / 4 성장기록 보관소 / 5 민원 접수 / 6 오늘의 운세`
     7번은 회색 + 자물쇠 + `2월 14일 개방`
  5. 하단 회색 바 — 픽셀체 `VISITORS` + 검정 배경에 초록 LED 숫자 `0 0 3 6 5` (한 칸씩 분리)
- **포인트** — 흐르는 공지, 방문자 카운터, 대기번호. 셋 다 있어야 "그 시절"이 됨

### A-03 · 1번 창구 발급물 (연애 1주년 증명서)

- **목적** — 저장해서 카톡 프로필에 걸 결과물. 이 사이트의 클라이맥스
- **배경** — 진한 갱지색 (#E3D9C0), 그 위에 밝은 갱지 문서 (#EFE7D3)
- **요소 (위 → 아래)** — 전부 명조체
  1. 이중 테두리 (바깥 굵은 먹선 + 안쪽 얇은 선)
  2. 우측 상단 작게 `제 2026 - 001 호`
  3. 가운데 큰 제목, 자간 아주 넓게 — `연애 1주년 증명서`
  4. 표 (좌측 열은 진한 베이지 배경)
     `성 명 | 김○○ · 박○○`
     `교제개시일 | 2025. 02. 14.`
     `경 과 일 수 | 365일`
     `특 기 사 항 | 상습 애교 (3급)`
  5. 본문 — `위 두 사람은 위와 같이 1년간 교제하였음을 대한연애공사가 확인하여 이 증명서를 발급합니다.`
  6. 가운데 정렬 날짜 `2026년 2월 14일`
  7. 기관명 `대한연애공사` 크게 + 그 옆에 **빨간 원형 직인**, 11도 정도 기울어짐, 살짝 번짐

# 7. 기술 / 난이도

프레임워크 없어도 됩니다. 정적 사이트 + 브라우저 저장소면 끝.

| 기능 | 방법 | 난이도 |
|------|------|--------|
| 전체 | 정적 HTML/CSS/JS (또는 Vite + React) | 쉬움 |
| 배포 | Cloudflare Pages / Vercel — 무료 | 아주 쉬움 |
| 증명서 이미지 저장 | `html-to-image`로 PNG 저장 | 쉬움 |
| PDF | `jsPDF`에 위 PNG 얹기 (모바일은 PNG 권장) | 쉬움 |
| 사진첩 | `public/photos/` + `photos.json` 한 파일 | 아주 쉬움 |
| 키우기 · 마일리지 | `localStorage` + 날짜 비교 | 쉬움 |
| 108번 탭 | 카운터 + `navigator.vibrate` | 쉬움 |
| 성장 기록 | 미리 만든 이미지 6장 + 슬라이더 | 쉬움 |
| 입장 코드 | 클라이언트에서 문자열 비교 (보안 아님, 연출) | 아주 쉬움 |
| 당일 해금 | `new Date()` 비교 | 아주 쉬움 |
| 민원 접수 | 폼 → 메일 전송 서비스 또는 구글폼 | 쉬움 |

**서버 없음 · DB 없음 · 로그인 없음.** 이게 난이도를 낮추는 핵심입니다.

## 주의할 것

- **모바일 우선.** 남친은 카톡 링크로 폰에서 엽니다. 데스크톱은 나중
- 자동 재생 음악은 iOS에서 막힘 → 음소거 버튼을 눌러야 나오게
- `localStorage`는 브라우저 지우면 날아감 → 중요한 것(편지)을 여기 의존시키지 말 것
- 사진 용량. 원본 넣으면 느려짐 → 가로 1200px, webp로 줄여서
- 입장 코드는 보안이 아니라 연출. 소스 보면 다 보입니다 (그래도 상관없음)
