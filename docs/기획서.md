# 나비효과플랜 카페 키워드 원고 작업 프로그램 — 기획서

> 상태: **기획/목업 단계** (구현 착수 전, 검토용 문서) 개정: v0.2 — 2026-09-15 (수집 3단 구조, 제목 수정, 상단 키워드·요청사항, 댓글 세트 재사용, 티키타카 반영)

---

## 1. 무엇을 만드는가

키워드 하나를 넣으면 **네이버 카페에 바로 올릴 수 있는 원고 1세트**가 나오는 작업 도구입니다. 원고 1세트 = `[제목]` + `[본문]` + `[댓글 세트]` n개(기본 4개, 각 댓글은 티키타카 여러 턴 가능).

지금 수작업으로 하는 흐름 — 키워드 잡기 → 잘 나간 카페 글 찾아 읽기 → 본문 쓰기 → 댓글 붙이기 → 문서로 정리해 전달 → 카페에 업로드 — 을 한 화면에서 끝내는 것이 목표입니다.

### 핵심 원칙

| 원칙 | 의미 |
| --- | --- |
| 원고는 **제목 + 본문 + 댓글 세트**가 한 덩어리 | 따로 만들지 않고 같이 생성·같이 버전 관리 |
| 다시 만들기가 아니라 **고쳐 만들기** | 댓글 3번만 바꾸고 싶을 때 나머지는 그대로 유지 |
| 댓글은 한 줄이 아니라 **대화** | 댓글 하나 안에서 작성자와 여러 번 티키타카 |
| 좋은 댓글 세트는 **자산** | 본문을 못 쓰는 원고라도 댓글 세트는 그대로 재사용 |
| **내 스타일**을 학습 | 기존 작업 파일·카페 URL을 넣으면 그 어투로 씀 |
| 결과물은 **전달 가능한 형태** | 복사 / 파일 / Google Docs |

## 2. 사용자 플로우

```
①  키워드 + 요청사항 입력 ──────────────────┐
    (+ 업체/지역/타깃/톤/분량/댓글 수)        │
                                            ▼
②  [선택] 보관함 채우기                 ③ 1차 생성
    · 기존 작업 파일 업로드                  │  제목 + 본문 + 댓글 세트
    · 네이버 카페 글 수집 (3단 구조)          │
    · 직접 붙여넣기                          ▼
                                       ④ 부분 수정 → 2차·3차 생성
                                            │  · 카드별 수정 지시
                                            │  · 댓글별 티키타카 턴 수 조절
                                            │  · 상단에서 키워드·요청사항 교체
                                            │  · 다른 원고의 댓글 세트 그대로 가져오기
                                            ▼
                                       ⑤ 저장 / 내보내기
                                            │  복사 · .txt · Google Docs
                                            ▼
                                       ⑥ [준비] 네이버 카페 업로드
```

## 3. 화면 구성

전체 5개 탭. PC는 좌측 사이드 탭, 모바일은 하단 탭바로 같은 화면을 씁니다.

### 3-1. 원고 생성

| 입력 항목     | 필수 | 설명                                                                      |
| ------------- | ---- | ------------------------------------------------------------------------- |
| 핵심 키워드   | ✅   | 예: `강남 임플란트 잘하는곳`                                              |
| **요청사항**  |      | 이번 원고에 대한 자유 지시. 예: `상담 3곳 비교 흐름으로 / 가격 단정 금지` |
| 업체·브랜드명 |      | 본문에 자연스럽게 노출할 이름                                             |
| 지역          |      | 지역 카페 글에 필요                                                       |
| 타깃 독자     |      | 예: `30~50대 직장인`                                                      |
| 카페 성격     |      | 예: `지역 맘카페`, `자취 정보 카페`                                       |
| 톤앤매너      |      | 후기형 / 정보형 / 질문형 / 추천형                                         |
| 본문 분량     |      | 짧게(700~~1,000자) / 보통(1,100~~1,500자) / 길게(1,600~2,200자)           |
| 댓글 개수     |      | 2~10개 (기본 4개)                                                         |
| **댓글 세트** |      | `새로 생성` 또는 `보관함에서 가져오기`                                    |
| 쓰지 말 표현  |      | 금칙어, 경쟁사명 등                                                       |

생성 버튼을 누르면 결과가 **실시간으로** 흘러나오고, 완료되면 제목 카드 · 본문 카드 · 댓글 카드 n개로 정리됩니다.

### 3-2. 원고 보관함

지금까지 작업한 텍스트 파일이 많다는 전제로 만든 화면입니다. 파일 목록이 아니라 **키워드 카드**로 봅니다.

#### 폴더 통째로 올리기

폴더를 끌어다 놓으면 하위 폴더까지 한 번에 읽습니다. 파일 하나당 원고 하나로 처리합니다.

| 단계 | 하는 일 |
| --- | --- |
| 1. 키워드 추출 | 파일명에서 키워드를 뽑습니다. `강남임플란트_원고_최종v2.txt` → **강남 임플란트** |
| 2. 내용 나누기 | 제목 · 본문 · 댓글 세트를 구분하고, 댓글의 티키타카 순서까지 살려 저장 |
| 3. 확인 필요 분리 | 형식이 달라 못 나눈 파일만 따로 모아 직접 지정 |

**키워드 추출 규칙** — 확장자 제거 → `_` `-` 를 띄어쓰기로 → 꼬리말 제거 (`원고`, `최종`, `수정`, `수정본`, `복사본`, `v2`, `(1)`, `0912` 같은 날짜·버전 표기) → 남은 말이 키워드. 추출 결과는 언제든 카드에서 직접 고칠 수 있습니다.

#### 키워드 카드

카드 한 장 = 원고 하나. 큰 글씨가 **키워드**이고, 아래에 제목 한 줄과 요약이 붙습니다.

| 카드에 보이는 것    | 예                                                  |
| ------------------- | --------------------------------------------------- |
| 키워드              | `브라질리언 왁싱 모낭염`                            |
| 제목                | `왁싱하고 좁쌀 올라온 거, 저는 이렇게 가라앉혔어요` |
| 댓글 요약           | `댓글 4개 · 티키타카 4·2·2·1턴`                     |
| 올린 날 · 최근 사용 | `2026.07.03 · 오늘`                                 |
| 파일명              | `브라질리언왁싱_모낭염_원고.txt`                    |
| 버튼                | `댓글세트 쓰기` · `원고 보기` · `어투 학습` 체크    |

#### 검색 · 정렬

- **검색** — 키워드 · 제목 · 파일명을 한 칸에서 찾습니다. 입력하는 즉시 걸러집니다
- **정렬** — `최근 올린 순` / `키워드 가나다순` / `댓글 많은 순` / `최근 쓴 순`
- 상단 요약 줄에 `파일 n개 · 키워드 인식 n개 · 확인 필요 n개 · 어투 학습 n개` 표시

#### 보관함이 쓰이는 두 곳

1. **어투 학습** — 체크한 원고의 문체를 생성에 반영 (7장)
2. **댓글 세트 재사용** — 카드의 `댓글세트 쓰기` 버튼 (6장)

카페에서 수집한 글도 같은 보관함에 키워드 카드로 들어갑니다(8장).

### 3-3. 결과 · 버전 (2차 · 3차 생성)

이 프로그램의 핵심 화면입니다.

**상단 작업 바** — 화면 맨 위에 `키워드`와 `요청사항` 입력칸이 항상 붙어 있습니다. 여기서 값을 바꾸고 `이 조건으로 전체 다시 생성`을 누르면 새 조건으로 새 버전이 나옵니다. (생성 화면으로 돌아갈 필요 없음)

**카드 구성** — 위에서부터

| 카드              | 수정 방법                                                   |
| ----------------- | ----------------------------------------------------------- |
| **제목**          | 카드에 붙은 수정 지시칸. 예: `숫자 빼고 질문형으로`         |
| **본문**          | 카드에 붙은 수정 지시칸. 예: `견적 비교 부분 더 구체적으로` |
| **댓글1 ~ 댓글n** | 수정 지시칸 + **티키타카 턴 수 선택(1~6턴)**                |

**댓글 세트 바** — 댓글 영역 머리에 `다른 원고에서 가져오기` 버튼. 가져온 세트는 `가져온 세트 · 재생성 안 함` 표시가 붙고, 다음 버전을 만들어도 **글자 그대로 유지**됩니다.

**버전 관리** — 상단 `v1 · v2 · v3 …` 탭. 언제든 이전 버전으로 되돌리기 / 비교. `다음 버전 생성`을 누르면 **수정 지시를 적은 카드만** 새로 쓰고 나머지는 글자 그대로 남습니다.

### 3-4. 내보내기

| 방법                       | 설명                                           |
| -------------------------- | ---------------------------------------------- |
| 전체 복사                  | 제목+본문+댓글 전체를 클립보드로               |
| 본문만 복사                | 카페 글쓰기 창에 그대로 붙여넣기               |
| 댓글 세트 복사             | 티키타카 순서대로, 작성자 답글까지             |
| 파일 저장                  | `.txt` / `.md`                                 |
| **Google Docs로 내보내기** | 구글 계정 연결 후 새 문서 생성, 링크 바로 열기 |

문서 제목 규칙(기본값): `[나비효과플랜] {키워드} 원고 v{버전} ({날짜})`

### 3-5. 네이버 업로드 — **준비 단계**

이번 단계에서는 **화면과 설계만** 만들고 실제 업로드는 켜지 않습니다. 자세한 내용은 10장.

## 4. 원고 데이터 구조

생성 결과는 아래 마커 형식으로 주고받습니다. 파싱이 단순하고, 사람이 읽어도 그대로 원고입니다.

```
[제목]
강남 임플란트 잘하는곳 세 군데 상담받고 결정하기까지

[본문]
작년 가을부터 오른쪽 아래 어금니가…

[댓글1] 티키타카 4턴
(40대 직장인 남성) 저도 지금 딱 그 고민 중인데, 상담 비용은 따로 들었나요?
└작성자: 저는 세 곳 다 상담이랑 CT는 따로 안 받았어요.
└(40대 직장인 남성) 아 그렇군요. 견적은 많이 차이 났나요?
└작성자: 제일 싼 곳이랑 백 단위로 차이 났어요.

[댓글2] 티키타카 2턴
(30대 워킹맘) 점심시간에 잠깐 다녀올 수 있는 거리인가요?
└작성자: 역삼역에서 걸어서 5분 정도예요.
```

- 댓글 첫 줄의 `(…)`는 화자 페르소나
- `└작성자:` 는 글쓴이 답글, `└(페르소나)` 는 댓글 작성자의 재답글
- 턴 수는 댓글마다 다르게 지정 가능 (1~6턴)

내부 저장 형태:

```jsonc
{
  "id": "doc_xxx",
  "keyword": "강남 임플란트 잘하는곳",
  "request": "상담 3곳 비교 흐름으로 / 가격 단정 금지",
  "options": { "tone": "review", "length": "medium", "commentCount": 4 },
  "versions": [
    {
      "no": 1,
      "createdAt": "2026-09-15T04:10:00Z",
      "title": "...",
      "body": "...",
      "comments": [
        {
          "index": 1,
          "persona": "40대 직장인 남성",
          "locked": false, // 가져온 세트면 true → 재생성해도 유지
          "importedFrom": null, // 가져온 원본 원고 id
          "thread": [
            { "by": "commenter", "text": "..." },
            { "by": "author", "text": "..." },
            { "by": "commenter", "text": "..." },
            { "by": "author", "text": "..." },
          ],
        },
      ],
    },
    { "no": 2, "revisedParts": ["title", "comment3"], "...": "..." },
  ],
}
```

## 6. 댓글 세트 재사용

> "브라질리언 모낭염 원고의 본문은 못 쓰지만, 댓글 세트는 그대로 써도 되는 경우가 있다"

이 경우를 정식 기능으로 만듭니다. **들어가는 입구가 두 군데**입니다.

### 입구 1 — 원고 생성 화면 (기본 생성 단계)

`댓글 세트` 항목에서 `기존 댓글세트 불러오기`를 고르면 원고 선택 패널이 열립니다.

```
[ ] 새로 생성     [v] 기존 댓글세트 불러오기     [ 원고 선택 ]
        ↓
  ┌──────────────────────────────────────────┐
  │ 키워드로 원고 찾기 — 예: 모낭염            │  ← 검색
  ├──────────────────────────────────────────┤
  │ 브라질리언 왁싱 모낭염                     │
  │ 댓글 4개 · 티키타카 4·2·2·1턴 · 2026.07.03 │ [이 세트 쓰기]
  │ 강남 임플란트 잘하는곳                     │
  │ 댓글 4개 · 티키타카 4·2·2·1턴 · 2026.09.12 │ [이 세트 쓰기]
  └──────────────────────────────────────────┘
        ↓
  선택됨: 브라질리언 왁싱 모낭염 · 댓글 4개   [바꾸기] [해제]
```

이 상태에서 원고를 생성하면 **본문·제목만 새로 쓰고 댓글은 고른 세트를 그대로** 붙입니다.

### 입구 2 — 보관함 카드 / 결과 화면

- 보관함 카드의 `댓글세트 쓰기` 버튼 → 바로 작업 중인 원고에 적용
- 결과 화면 댓글 영역의 `다른 원고에서 가져오기` → 같은 검색 패널

### 가져온 뒤의 동작

1. 가져온 댓글에는 `가져온 세트 · 재생성 안 함` 표시가 붙고 잠깁니다
2. `다음 버전 생성`을 눌러도 **글자 하나 바뀌지 않습니다**
3. 일부만 바꾸고 싶으면 그 댓글에만 수정 지시를 적으면 그 댓글만 새로 씁니다
4. 전부 되돌리려면 `새로 생성으로 되돌리기`

### 저장되는 것

보관함에 원고를 넣을 때 **댓글의 티키타카 구조까지 그대로** 저장합니다. (누가 몇 번째로 말했는지, 작성자 답글인지 댓글러 재답글인지) 카페에서 수집한 글도 대댓글 관계를 보존하므로, 수집한 글의 댓글 세트도 재사용 대상입니다.

## 7. 어투 학습 방식

별도 모델 학습(파인튜닝)이 아니라 **생성할 때마다 참고 원고를 같이 넣어 주는 방식**입니다.

- 장점: 자료를 넣자마자 바로 반영, 자료 교체가 자유로움, 추가 비용 없음
- 방식: 체크한 참고 원고(최대 6편, 편당 4,000자)를 프롬프트에 함께 전달
- 지시: _"문장 길이·단락 나누기·자주 쓰는 어미·댓글 호흡·티키타카 패턴을 흉내 내되 내용은 베끼지 말 것"_

## 8. 네이버 카페 원문 수집 — **항상 되게 만드는 3단 구조**

### 왜 한 가지 방법으로는 안 되는가

카페 글은 iframe 안에 있어 주소를 그냥 긁으면 내용이 안 나옵니다. 그래서 카페 웹/앱이 실제로 쓰는 공개 조회 API를 호출하는 게 1차 방법입니다. 이건 잘 동작합니다 — **공개 글이라면.**

문제는 실패가 "가끔 랜덤으로" 나는 게 아니라 **조건이 맞으면 항상 실패**한다는 점입니다.

- 비공개 카페 / 가입 등급 제한 글 → 로그인 없이는 영구히 못 읽음
- 서버(클라우드 IP)에서의 호출 → 차단 정책이 바뀌면 그날부터 전부 실패

그래서 **한 방법에 걸지 않고, 자동으로 다음 단계로 넘어가는 3단 구조**로 만듭니다.

### 1단계 — 서버가 바로 수집 (기본값)

- URL 5종 형식(`cafe.naver.com/이름/글번호`, `/ca-fe/cafes/…`, `iframe_url=…`, 모바일 주소, `naver.me` 단축) 파싱 → `cafeId` / `articleId` 추출
- 벌명주소는 숫자 ID로 변환 후 본문 API · 댓글 API 호출
- **대댓글 관계까지 구조 그대로** 수집 (티키타카 학습·재사용에 그대로 사용)
- HTML → 읽는 텍스트로 정리해 보관함에 저장
- 실패(403 / 404 / 빈 응답 / 로그인 요구) 판정 시 **자동으로 2단계 안내**

> 공개 글은 대부분 여기서 끝납니다. 사용자는 주소만 붙여넣습니다.

### 2단계 — 내 브라우저에서 수집 (`수집 버튼`)

즐겨찾기에 한 번 등록해 두는 **수집 버튼(북마클릿)** 입니다.

- 카페 글을 연 상태에서 버튼을 누르면, **지금 로그인된 내 계정 기준으로** 페이지 안의 제목·본문·댓글을 읽어 작업실로 보냅니다
- **비공개 카페 · 등급 제한 글도 읽힙니다** (내가 볼 수 있는 글이면 전부)
- 서버 IP 차단 같은 변수가 아예 없습니다 — 평소 쓰던 브라우저의 평범한 열람과 동일
- 아이디·비밀번호를 프로그램이 알 필요가 없습니다
- 비용: 글을 직접 열고 버튼 한 번 누르는 수고

### 3단계 — 직접 붙여넣기

본문과 댓글을 그대로 붙여넣습니다. 어떤 상황에서도 쓸 수 있는 최후 수단이며 항상 열려 있습니다.

### 구현 1일차 검증 계획

기획 승인 후 가장 먼저, 다음을 실제로 돌려서 성공률을 표로 보고드립니다.

| 검증 대상                          | 개수 | 확인 항목                                  |
| ---------------------------------- | ---- | ------------------------------------------ |
| 공개 카페 글                       | 10건 | 본문·댓글 수집 성공 여부, 대댓글 구조 보존 |
| 비공개 / 등급 제한 글              | 2건  | 1단계 실패 감지 → 2단계 전환이 매끄러운지  |
| 모바일 주소 · `naver.me` 단축 주소 | 4건  | URL 파싱 정확도                            |

> 이 문서를 쓰는 작업 환경에서는 네이버 도메인 접속이 막혀 있어 실측을 못 했습니다. 다만 **2·3단계가 있기 때문에 1단계 결과와 무관하게 "수집이 안 되는 글"은 없습니다.** 1단계 성공률은 "사용자가 얼마나 편한가"를 정할 뿐, 되고 안 되고를 가르지 않습니다.

### 수집 항목과 유의사항

- 수집: 제목, 본문 텍스트, 댓글(작성순), 대댓글 관계, 댓글 수
- 저장 안 함: 이미지 파일, 작성자 실명·연락처 등 개인정보
- 수집한 글은 **어투·구성 참고용 + 댓글 세트 재사용용**입니다. 본문 문장을 그대로 가져다 쓰지 않도록 프롬프트에서 막습니다(저작권)

## 12. 확인이 필요한 사항

1. **파일명 규칙** — 지금 파일명이 `강남임플란트_원고_최종v2.txt` 같은 형태인지, 아니면 다른 규칙인지 알려주시면 키워드 추출 규칙을 거기 맞춰 잡겠습니다. 실제 파일 20~30개 목록만 보여주셔도 충분합니다.
2. **기존 작업 원고 파일** — 3~5편만 주시면 목업 예시를 실제 스타일로 교체하고, 어투 학습 프롬프트도 그 어투에 맞춰 조정하겠습니다. 댓글 세트 재사용 기능도 실제 세트로 테스트할 수 있습니다.
3. **티키타카 기본값** — 지금은 댓글마다 1~6턴을 따로 고르게 해 뒀고, 기본은 `댓글1 = 4턴 / 댓글2 = 2턴 / 나머지 = 1~2턴`으로 잡았습니다. 실제 운영 패턴이 다르면 알려주세요.
4. **주력 업종** — 병원/시술, 왁싱/피부, 인테리어 등 주력 분야를 알려주시면 기본값과 금칙어 목록을 미리 채워 둘 수 있습니다.
5. **사용 인원** — 혼자 쓰실지 팀이 함께 쓸지에 따라 보관함 저장 방식(내 브라우저 vs 서버 공유)이 달라집니다. 댓글 세트를 팀원끼리 공유하려면 서버 저장이 필요합니다.
