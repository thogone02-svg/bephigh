# 나비효과플랜 카페 키워드 원고 작업 프로그램 — 기획서

> 상태: **기획/목업 단계** (구현 착수 전, 검토용 문서) 최종 수정: 2026-09-15

---

## 1. 무엇을 만드는가

키워드 하나를 넣으면 **네이버 카페에 바로 올릴 수 있는 원고 1세트**가 나오는 작업 도구입니다. 원고 1세트 = `[본문]` 1개 + `[댓글 세트]` n개(기본 4개).

지금 수작업으로 하는 흐름 — 키워드 잡기 → 잘 나간 카페 글 찾아 읽기 → 본문 쓰기 → 댓글 4개 붙이기 → 문서로 정리해 전달 → 카페에 업로드 — 을 한 화면에서 끝내는 것이 목표입니다.

### 핵심 원칙

| 원칙                                    | 의미                                           |
| --------------------------------------- | ---------------------------------------------- |
| 원고는 **본문 + 댓글 세트**가 한 덩어리 | 따로 만들지 않고 같이 생성·같이 버전 관리      |
| 다시 만들기가 아니라 **고쳐 만들기**    | 댓글 3번만 바꾸고 싶을 때 나머지는 그대로 유지 |
| **내 스타일**을 학습                    | 기존 작업 파일·카페 URL을 넣으면 그 어투로 씀  |
| 결과물은 **전달 가능한 형태**           | 복사 / 파일 / Google Docs                      |

## 2. 사용자 플로우

```
①  키워드 입력 ─────────────────────────────┐
    (+ 업체/지역/타깃/톤/분량/댓글 수)        │
                                            ▼
②  [선택] 학습자료 등록                 ③ 1차 생성
    · 기존 작업 파일 업로드                  │  본문 + 댓글1~4 동시 생성
    · 네이버 카페 URL 수집                   │
    · 직접 붙여넣기                          ▼
                                       ④ 부분 수정 → 2차·3차 생성
                                            │  "댓글2를 더 짧고 의심하는 톤으로"
                                            │  수정 지시 없는 부분은 그대로 유지
                                            ▼
                                       ⑤ 저장 / 내보내기
                                            │  복사 · .txt · Google Docs
                                            ▼
                                       ⑥ [준비] 네이버 카페 업로드
```

## 3. 화면 구성

전체 5개 탭. PC는 좌측 사이드 탭, 모바일은 하단 탭바로 같은 화면을 씁니다.

### 3-1. 원고 생성

| 입력 항목          | 필수 | 설명                                                       |
| ------------------ | ---- | ---------------------------------------------------------- |
| 핵심 키워드        | ✅   | 예: `강남 임플란트 잘하는곳`                               |
| 업체·브랜드명      |      | 본문에 자연스럽게 노출할 이름                              |
| 지역               |      | 지역 카페 글에 필요                                        |
| 타깃 독자          |      | 예: `30~40대 직장인`                                       |
| 카페 성격          |      | 예: `지역 맘카페`, `자취 정보 카페`                        |
| 톤앤매너           |      | 후기형 / 정보형 / 질문형 / 추천형                          |
| 본문 분량          |      | 짧게(700~~1000자) / 보통(1100~~1500자) / 길게(1600~2200자) |
| 댓글 개수          |      | 2~10개 (기본 4개)                                          |
| 반드시 포함할 내용 |      | 이벤트 문구, 위치 설명 등                                  |
| 쓰지 말 표현       |      | 금칙어, 경쟁사명 등                                        |

생성 버튼을 누르면 결과가 **한 글자씩 실시간으로** 흘러나오고, 완료되면 본문 카드 1개 + 댓글 카드 n개로 정리됩니다.

### 3-2. 학습자료 (스타일 학습)

세 가지 방법으로 참고 원고를 쌓습니다.

1. **파일 업로드** — 기존에 작업하신 `.txt` / `.md` / `.docx` 원고
2. **네이버 카페 URL** — 주소를 넣으면 제목·본문·댓글을 자동 수집
3. **직접 붙여넣기** — 위 두 방법이 막힐 때(비공개 카페 등)

등록된 자료는 목록으로 보이고 **체크박스로 이번 생성에 쓸 것만 선택**합니다. 자료가 하나도 없어도 생성은 됩니다(기본 스타일).

### 3-3. 결과 · 버전 (2차 · 3차 생성)

이 프로그램의 핵심 화면입니다.

- 본문 카드, 댓글1~n 카드가 세로로 나열됨
- **각 카드마다 "수정 지시" 입력칸**이 따로 붙어 있음
  - 예) 댓글2 → `더 짧게, 살짝 의심하는 톤으로`
  - 예) 댓글4 → `문의 유도 문구 넣어줘`
- `다음 버전 생성` 버튼 → **지시를 적은 카드만 새로 쓰고, 나머지는 글자 그대로 유지**
- 상단에 `v1 · v2 · v3 …` 버전 탭 — 언제든 이전 버전으로 되돌리기 / 비교

### 3-4. 내보내기

| 방법                       | 설명                                           |
| -------------------------- | ---------------------------------------------- |
| 전체 복사                  | 본문+댓글 전체를 클립보드로                    |
| 본문만 / 댓글만 복사       | 카페 업로드할 때 실제로 쓰는 단위              |
| 파일 저장                  | `.txt` / `.md`                                 |
| **Google Docs로 내보내기** | 구글 계정 연결 후 새 문서 생성, 링크 바로 열기 |

문서 제목 규칙(기본값): `[나비효과플랜] {키워드} 원고 v{버전} ({날짜})`

### 3-5. 네이버 업로드 — **준비 단계**

이번 단계에서는 **화면과 설계만** 만들고 실제 업로드는 켜지 않습니다.

- 계정 연결, 카페/게시판 선택, 예약 시간 UI는 미리 배치
- 버튼은 비활성 + `준비 중` 배지
- 왜 준비만 하는지, 켤 때 무엇이 필요한지는 아래 8장 참고

## 4. 원고 데이터 구조

생성 결과는 아래 마커 형식으로 주고받습니다. 파싱이 단순하고, 사람이 읽어도 그대로 원고입니다.

```
[제목]
강남 임플란트 3군데 상담 받고 결정한 후기

[본문]
작년부터 어금니가 시큰거려서…

[댓글1]
(40대 직장인 남성) 저도 지금 딱 그 고민 중인데 상담비는 얼마 나왔나요?
└ 작성자: 저는 상담은 무료였어요~

[댓글2]
(30대 워킹맘) 글 잘 봤어요. 회사 점심시간에 다녀올 수 있는 거리인가요?
```

내부 저장 형태:

```jsonc
{
  "id": "doc_xxx",
  "keyword": "강남 임플란트",
  "options": { "tone": "review", "length": "medium", "commentCount": 4, ... },
  "versions": [
    {
      "no": 1,
      "createdAt": "2026-09-15T04:10:00Z",
      "title": "...",
      "body": "...",
      "comments": [{ "index": 1, "persona": "40대 직장인 남성", "text": "..." }]
    },
    { "no": 2, "revisedParts": ["comment2", "comment4"], ... }
  ]
}
```

## 6. 스타일 학습 방식

별도 모델 학습(파인튜닝)이 아니라 **생성할 때마다 참고 원고를 같이 넣어 주는 방식**입니다.

- 장점: 자료를 넣자마자 바로 반영, 자료 교체가 자유로움, 추가 비용 없음
- 방식: 선택된 참고 원고(최대 6편, 편당 4,000자)를 프롬프트에 함께 전달
- 지시: _"문장 길이·단락 나누기·자주 쓰는 어미·댓글 호흡을 흉내 내되 내용은 베끼지 말 것"_

자료가 6편을 넘어가면 최근 것 우선 또는 사용자가 체크한 것만 사용합니다.

## 7. 네이버 카페 원문 수집 — 방식과 한계

카페 글은 iframe 안에 들어 있어 주소를 그냥 긁으면 내용이 안 나옵니다. 그래서 카페 웹/앱이 실제로 쓰는 **공개 조회 API**를 그대로 호출합니다.

1. 붙여넣은 URL에서 `cafeId` / `articleId` 추출 (주소 형식 5종 대응)
2. 벌명주소(`cafe.naver.com/이름`)면 숫자 ID로 변환
3. 본문 API 호출 → 제목·본문 HTML·댓글 수신
4. HTML을 사람이 읽는 텍스트로 정리해 학습자료로 저장

**한계 (미리 알고 계셔야 하는 부분)**

- **로그인 없이 읽히는 공개 글만** 수집됩니다. 비공개 카페·등급 제한 글은 불가
- 네이버가 응답 형식을 바꾸면 수집이 멈출 수 있음 → 그때를 대비해 **직접 붙여넣기** 경로를 항상 열어 둠
- 수집한 글은 **스타일 참고용**입니다. 문장을 그대로 가져다 쓰지 않도록 프롬프트에서 막습니다(저작권)

## 8. 심화 — 네이버 카페 자동 업로드 (이번엔 준비만)

### 왜 바로 안 켜는가

| 항목 | 내용 |
| --- | --- |
| 로그인 | 네이버는 아이디·비밀번호 자동 로그인을 차단합니다(캡차·기기 인증·2단계 인증). 서버가 비밀번호를 직접 넣는 방식은 계정 잠김 위험이 큽니다 |
| 보관 | 아이디/비밀번호를 서버에 저장하는 구조 자체가 사고 시 피해가 큽니다 |
| 약관 | 카페 자동 등록은 네이버 운영정책 확인이 필요합니다 |

### 준비해 둘 것 (이번 단계 산출물)

1. **화면**: 계정 연결 · 카페/게시판 선택 · 예약 발행 UI (비활성 상태로 배치)
2. **데이터 구조**: 업로드 요청 형식(카페ID, 게시판ID, 제목, 본문, 댓글 목록, 예약시간) 확정
3. **API 자리**: `POST /api/naver/publish` 엔드포인트를 만들되 `501 준비 중` 응답
4. **문서**: 실제로 켤 때 택할 수 있는 3가지 방식 정리

### 켤 때 선택지 (권장순)

| 방식 | 설명 | 안전도 |
| --- | --- | --- |
| **A. 브라우저 확장/스크립트** | 사용자가 자기 브라우저에서 이미 로그인한 상태로 글 등록. 비밀번호를 서버가 모름 | ⭐⭐⭐ 권장 |
| **B. 쿠키 연결** | 사용자가 로그인 쿠키를 한 번 넣어 두면 서버가 그 세션으로 등록. 쿠키 만료 시 재연결 | ⭐⭐ |
| **C. 서버 자동 로그인** | 아이디·비밀번호 저장 후 서버가 로그인 | ⭐ 비권장 |

→ **A안(브라우저에서 등록)** 을 기본으로 설계해 두겠습니다. 실제 개발 착수는 대표님 확인 후.

## 9. 기술 구성

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 실행 환경 | Cloudflare Workers | 지금 저장소가 이미 Workers 구성, 서버 관리 불필요, 국내 응답 빠름 |
| 화면 | HTML + CSS + JS (빌드 없음) | 가볍고 모바일 최적화 쉬움, 유지보수 단순 |
| 원고 생성 | Claude API (`claude-opus-5`) | 한국어 장문 품질, 지시 반영 정확도 |
| 저장 | 브라우저 로컬 저장 (1단계) | 서버에 원고를 안 남김. 팀 공유가 필요해지면 2단계에서 서버 저장 추가 |
| 문서 내보내기 | Google Docs API (브라우저에서 직접 호출) | 서버가 구글 비밀키를 들고 있지 않아도 됨 |

**필요한 키 (운영 시)**

- `ANTHROPIC_API_KEY` — 원고 생성 (필수)
- `GOOGLE_CLIENT_ID` — Google Docs 내보내기 (선택)

## 11. 확인이 필요한 사항

1. **기존 작업 원고 파일** — 아직 전달받지 못했습니다. 3~5편만 주시면 목업 예시를 실제 스타일로 교체하고, 스타일 학습 프롬프트도 그 어투에 맞춰 조정하겠습니다.
2. **주력 업종** — 병원/시술, 인테리어, 학원 등 주력 분야를 알려주시면 기본값과 금칙어 목록을 미리 채워 둘 수 있습니다.
3. **사용 인원** — 대표님 혼자 쓰실지, 팀이 함께 쓸지에 따라 저장 방식(로컬 vs 서버 공유)이 달라집니다.
4. **댓글 기본 개수** — 4개로 잡았습니다. 실제 운영 기준이 다르면 알려주세요.
