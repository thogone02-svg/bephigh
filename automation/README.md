# 카페 자동 업로드

웹앱은 브라우저 안에서만 돌아서 네이버에 대신 글을 못 올려요. 이 폴더가 그 일을 합니다.
사장님 컴퓨터에서 도는 작은 프로그램이고, 웹앱에서 내려받은 파일을 읽어서 정해둔 순서와 간격대로 올립니다.

## 아이디와 비밀번호는 저장하지 않습니다

계정마다 브라우저 프로필을 따로 만들어 둡니다. 처음 한 번만 **직접 로그인**해 두면,
그 다음부터는 네이버가 발급한 쿠키를 다시 쓰는 방식이에요.
그래서 비밀번호를 어디에도 적어둘 필요가 없고, 캡차나 기기 등록에도 잘 안 걸립니다.

프로필은 `profiles/` 에 쌓이고 깃에는 올라가지 않아요.

## 터미널이 번거로우면

폴더 안의 **시작하기** 파일을 두 번 누르세요.
윈도우는 `시작하기.bat`, 맥은 `시작하기.command` 입니다.
준비부터 로그인, 연습, 진짜 올리기까지 번호로 골라서 할 수 있어요.

아래는 터미널로 직접 할 때입니다.

## 처음 한 번만

```bash
cd automation
npm install
npm run setup
```

## 계정 파일 (넣으면 편해요)

웹앱 **업로드 → 계정**에서 `계정 파일 내려받기` 로 받은 `accounts.json` 을 이 폴더에 두세요.
아이디와 비밀번호를 적어 두셨다면 로그인할 때 알아서 채워 넣고,
올리는 중에 로그인이 풀려도 알아서 다시 들어갑니다.

안 넣으셔도 됩니다. 그때는 직접 로그인해 둔 기록만 씁니다.
이 파일에는 비밀번호가 들어 있으니 남에게 주지 마세요. 깃에는 안 올라갑니다.

## 계정 등록 (계정마다 한 번)

웹앱 **업로드 → 자리 배정**에서 고른 별칭과 **똑같은 이름**으로 해주세요.

```bash
npm run login -- "본문용"
npm run login -- "댓글용1"
npm run login -- "댓글용2"
```

창이 뜨면 그 계정으로 직접 로그인하고, 끝나면 창을 그냥 닫으시면 됩니다.

로그인이 살아 있는지 확인:

```bash
node check.mjs
```

## 올리기

웹앱 **업로드** 화면에서 `자동 업로드 파일 내려받기` 를 누르면 `키워드 업로드.json` 이 받아집니다.
그 파일을 이 폴더에 두고:

```bash
npm start -- "말라세지아 모낭염 업로드.json"
```

처음에는 연습부터 해보세요. 등록 버튼만 안 누르고 나머지는 똑같이 해봅니다.

```bash
npm start -- "말라세지아 모낭염 업로드.json" --dry
```

## 도는 동안

- 계정이 하나라도 로그아웃돼 있으면 **아무것도 올리기 전에** 멈추고 알려줍니다.
- 단계마다 창이 떴다 닫힙니다. 컴퓨터를 켜두셔야 해요.
- 중간에 막히면 그 창을 열어둔 채로 멈춥니다. 그 단계만 직접 올리시고,
  나머지는 웹앱 `올리는 순서`에서 복사해서 쓰시면 됩니다.

## 잘 안 될 때

네이버 카페 화면은 가끔 바뀝니다. 버튼을 못 찾겠다고 하면 `cafe.mjs` 의 `SELECTORS` 만
고치면 돼요. 나머지 파일은 건드릴 필요 없습니다.

한 계정으로 짧은 시간에 많이 올리면 네이버가 제한을 걸 수 있습니다.
간격은 웹앱에서 1~5분으로 정하시고, 하루에 너무 몰아서 올리지 마세요.
