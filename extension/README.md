# 카페 올리기 확장

원고 작업실에서 누르면 네이버 카페에 순서와 간격대로 올려 주는 브라우저 확장입니다. Node.js도 터미널도 필요 없습니다.

## 까는 법 (한 번만)

1. 이 `extension` 폴더를 컴퓨터에 둡니다. 어디든 괜찮지만 지우지 마세요.
2. 브라우저 주소창에 `chrome://extensions` 를 칩니다. 웨일은 `whale://extensions`, 엣지는 `edge://extensions` 입니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 이 `extension` 폴더를 고릅니다.

목록에 「나비효과플랜 카페 올리기」가 보이면 끝입니다.

## 새 판으로 바꿀 때

깃허브에서 새로 받으셨으면 `extension` 폴더를 바꿔치기한 뒤 `chrome://extensions` 에서 이 확장의 **↻** 를 누르세요. 그래야 새 판으로 돕니다. 작업실 업로드 화면이 판이 낡았다고 알려주기도 합니다.

## 쓰는 법

1. 원고 작업실 **업로드** 화면을 엽니다.
2. 게시판 주소를 넣고, 계정 별칭을 만들고, 자리를 배정합니다.
3. **연습으로 올려 보기** 를 먼저 누르세요. 글은 다 채우고 등록만 안 누릅니다.
4. 괜찮으면 **업로드 시작**.

## 화면을 안 건드려요

작업실에서 **뒤에서 올리기** 를 켜 두면 카페 창을 최소화한 채로 돕니다. 보고 계신 화면 위로 창이 뜨지 않아요. 다만 브라우저는 켜 두셔야 합니다. 되는 걸 눈으로 보고 싶으시면 그 칸을 끄세요.

간격이 몇 분씩 벌어져도 괜찮습니다. 크롬이 확장을 잠깐 재워도 알람으로 깨어나 하던 자리에서 이어서 합니다.

## 계정이 여러 개일 때

단계마다 맡은 계정으로 알아서 바꿔 가며 올립니다. 아이디와 비밀번호를 적어 두셨으면 로그인도 알아서 합니다.

**로그인은 계정마다 한 번이면 됩니다.** 이미 그 계정으로 들어가 있으면 다시 로그인하지 않아요. 매번 다시 로그인하면 오히려 네이버가 보안문자를 띄워서 사람 손이 더 자주 필요해집니다.

보안문자나 새 기기 확인이 떠서 사람이 필요하면, **내려둔 창을 올려서 보여 드리고 3분 기다립니다.** 그 창에서 로그인을 끝내시면 알아서 이어서 올라가요.

비밀번호를 안 적어 두셨으면 **지금 브라우저에 로그인돼 있는 계정으로** 올리고, 작업실 화면에 그렇게 했다고 적어 둡니다. 아무도 로그인돼 있지 않으면 창을 올려서 로그인해 달라고 합니다. 계정을 갈아 끼우려면 아이디·비밀번호를 넣어 두시는 게 확실해요.

캡차가 뜨면 사람이 풀어야 해요. 그때는 창에서 풀어 주시면 이어서 갑니다.

## 안 될 때

네이버 카페 화면은 가끔 바뀝니다. 「무엇을 못 찾았어요」 라고 나오면 작업실 화면에 **그때 무엇이 보였는지**(주소·칸 이름·단추 글자)가 같이 뜹니다. 그걸 그대로 알려주시면 고칠 수 있어요.

칸을 찾는 규칙은 전부 `page.js` 안에 있습니다. 안쪽 틀(iframe)까지 모두 뒤지고, 클래스 이름보다 **칸에 적힌 안내말**과 **단추에 쓰인 글자**를 먼저 봅니다. 그래야 네이버가 클래스를 바꿔도 잘 버팁니다.

## 요청 엿보기 (창 없이 올리는 길로 가려고)

지금은 카페 화면에서 칸을 찾아 글자를 넣고 단추를 누릅니다. 그래서 네이버가 화면을 바꾸면 멈춰요. 화면 대신 **요청을 그대로 보내면** 창도 필요 없고 화면이 바뀌어도 안 깨집니다.

그 요청이 어떻게 생겼는지 보려고 작업실 업로드 화면에 **요청 엿보기**를 뒀습니다. 켜고 카페에서 직접 글을 하나 올린 뒤 **본 것 꺼내기**를 누르면, 그때 나간 주소와 보낸 내용이 나옵니다. 비밀번호와 쿠키는 적지 않습니다.

## 조심할 것

짧은 시간에 여러 계정으로 많이 올리면 네이버가 제한을 걸 수 있습니다. 간격은 작업실에서 1~5분으로 정하시고, 하루에 몰아서 올리지 마세요.
