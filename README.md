# 나비효과플랜 카페 원고 작업실

네이버 카페에 올릴 원고를 키워드 하나로 만드는 도구입니다. 원고 1세트 = 제목 + 본문 + 댓글 세트(티키타카 포함).

- 기획서: [`docs/기획서.md`](docs/기획서.md)
- 원고 파일 포맷: [`docs/원고-포맷.md`](docs/원고-포맷.md)
- 화면 시안: [`mockup/`](mockup/)

## 지금 되는 것

| 기능                                          | 상태                                 |
| --------------------------------------------- | ------------------------------------ |
| 키워드 → 제목·본문·댓글 생성 (실시간 출력)    | ✅                                   |
| 모델 고르기 (OpenAI · Google · Anthropic 9종) | ✅                                   |
| 고칠 곳만 다시 쓰기 (2차·3차 버전)            | ✅                                   |
| 글을 두 번 눌러 직접 고치기 · 자동 저장       | ✅                                   |
| 댓글 줄마다 사진 자리 표시                    | ✅                                   |
| 원고 보관함 (txt 올리기 · 검색 · 정렬)        | ✅                                   |
| 댓글 세트 재사용 (추천 3개 + 검색)            | ✅                                   |
| 내보내기 (txt 저장 · 복사)                    | ✅                                   |
| 구글 문서 내보내기                            | 준비 중 (지금은 txt로 받아 붙여넣기) |
| 카페 글 수집                                  | 준비 중                              |
| 네이버 업로드                                 | 준비 중                              |

원고와 보관함은 **쓰는 사람의 브라우저에만** 저장됩니다. 서버에 남지 않습니다.

## 돌려보기

```sh
pnpm install
pnpm start          # http://127.0.0.1:8787
```

## 배포

[`docs/배포.md`](docs/배포.md)를 보세요. 브라우저만으로 하는 방법과 터미널로 하는 방법이 둘 다 적혀 있습니다.

## 카페 자동 업로드를 안 만든 이유

네이버는 아이디·비밀번호 자동 로그인을 막습니다(캡차·기기 인증). 서버가 대신 로그인하는 방식은 잘 막히고, 계정이 잠길 수 있으며, 비밀번호를 서버에 보관해야 합니다.

그래서 **올리는 일은 사람이 하고, 순서와 간격만 프로그램이 잡아 주는** 방식으로 만들었습니다. 원고를 고르면 `본문 → 3분 뒤 댓글1 → 1분 뒤 작성자 답글 → …` 순서표가 나오고, 단계마다 복사 버튼이 붙습니다. 계정 정보는 저장하지 않습니다(별칭 메모만).

완전 자동이 필요하면 방식을 정하고 따로 논의해야 합니다.

## API 키

앱을 열고 **설정 → API 키**에서 넣습니다. 회사별로 한 번만 넣으면 됩니다.

- **OpenAI** — 기본 모델 GPT-5.6 Luna (원고 1건 약 3원)
- **Google** — Gemini 3.1 Flash-Lite
- **Anthropic** — Claude Haiku 4.5 / Sonnet 5

키는 브라우저에 저장되고, 요청할 때만 서버를 거쳐 해당 회사로 전달됩니다. 서버에 보관하지 않습니다.

**구글 문서 내보내기**를 쓰려면 구글 클라이언트 ID도 필요합니다. [Google Cloud Console](https://console.cloud.google.com/apis/credentials)에서 OAuth 클라이언트 ID(웹 애플리케이션)를 만들고, 승인된 자바스크립트 원본에 배포 주소를 넣은 뒤 설정 화면에 붙여넣으면 됩니다. Google Docs API도 켜야 합니다.

## 구조

```

src/index.js     Worker 라우터
src/lib/
  providers.js   OpenAI · Google · Anthropic 호출
  prompts.js     원고 생성·수정 프롬프트
  manuscript.js  원고 파일 읽기/쓰기
  http.js        JSON · 스트리밍 도우미
  naver-cafe.js  카페 글 수집
public/
  gdocs.js       구글 문서 내보내기
  collect.js     즐겨찾기용 카페 수집 버튼
```
